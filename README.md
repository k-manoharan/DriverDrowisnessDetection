# Driver Drowsiness Detection

## 📌 Overview
This repository contains a computer vision and machine learning project designed to detect driver drowsiness in real-time. The system monitors the driver's eyes and face to identify signs of fatigue, aiming to trigger alerts and prevent potential accidents. 

This project was developed as part of an **IPCV (Image Processing and Computer Vision) Mini-Project**.

## 📂 Repository Structure
* **`Experiment/`**: Contains experimental Jupyter Notebooks, preliminary data analysis, and model testing files.
* **`project/`**: Contains the main source code, final models, and operational scripts for the detection system.
* **`IPCV Mini-Project Report.pdf`**: Comprehensive documentation covering the project's methodology, architecture, datasets used, and final results.
